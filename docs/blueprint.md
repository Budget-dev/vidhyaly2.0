# **App Name**: Vidhyaly

## Core Features:

- Performance-Based Rank Predictor: An interactive dashboard component that calculates potential NEET rankings using statistical models and historical performance data.
- Subject Mastery Visualization: Progress-tracking cards displaying proficiency percentages across Physics, Chemistry, Botany, and Zoology with circular progress indicators.
- Smart Spaced-Repetition Revision: A dedicated revision module that tracks mastered topics and prompts reviews of difficult material using an adaptive schedule.
- Weak-Topic Analytics Engine: Detailed performance insights that break down test scores to highlight specific academic areas needing improvement through data visualization.
- Dynamic Study Planner: An automated scheduling feature that generates 'Today's Plan' with specific question targets and lesson goals based on user progress.
- Interactive Mock Test Portal: A high-fidelity testing interface that simulates actual exam conditions with full-syllabus and subject-specific modules.
- Digital Resource Library: A comprehensive repository of curated study materials, formula sheets, and chapter-wise notes for Physics, Chemistry, and Biology.

## Style Guidelines:

- Primary Color: Vibrant Academic Blue (#2563EB) used for primary CTAs and brand presence.
- Background Color: Crisp, clean Paper White (#F8FAFC) to emphasize content clarity and focus.
- Accent Color: Knowledge Teal (#1696B5) used for specific performance highlights and interactive UI markers.
- Headline Font: 'Playfair' (serif) to evoke a sense of prestigious academic excellence. Body Font: 'PT Sans' (sans-serif) for high readability in dense data contexts.
- A clean, multi-card 'Bento-box' style layout with soft rounded corners and high white space, ensuring clear hierarchy between metrics.
- Thin-stroke line icons that feel technical and modern, corresponding to academic tools like microscopes, charts, and test tubes.
- Smooth, subtle easing on data transitions (e.g., progress bars filling or score counts ticking up) to maintain a focused environment.
